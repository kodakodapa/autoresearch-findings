# Prior-art answer for R2 (K21: two readings of the probe atom for three-player modal agents)

Verdict: partial prior art.

- Mennen (2017) defines opponent tests for multiplayer modal agents explicitly: each test names a target player, an agent to test against and an action, which fixes one way of defining probe atoms in games with more than two players. He does not compare alternative readings.
- Not found: a comparison of two probe semantics (replacing only the evaluator by a defector versus replacing both other players) or a count of how outcomes change between them.

- Mennen, "Modal combat for games other than the prisoner's dilemma" (LessWrong / Alignment Forum, 2017): framework for modal agents in games with any number of players and actions (player types, ranks, opponent tests naming a target player, an agent to test against and an action); existence and Pareto theorems; no agent families with index laws, no enumeration.
