# Owner prior-art check for K51 (5031 rank-0 unexploitable self-cooperators up to size 15; only Box p is FairBot)

Verdict: partial.

- Same as K1 (R1), which K51 extends from size 12 to 15: no census or count of unexploitable self-cooperating modal agents exists. The question was asked on LessWrong (2026) and answered by examples: uniqueness holds to modal depth 1 and fails from depth 2 (Box Box p, FairBot over PA+1, Box^k p). K51 extends this to an exhaustive classification of rank-0 agents up to size 15.
- Write-up: frame as extending the LessWrong question and Hatfield-Dodds's result; say which known examples appear; unexploitable means truth in the standard model, as in Barasz et al.
