K3 says the following. In the full (standard) structure on any frame, take the rigid reading of the conjunction axiom, Ax1GenR, where Φ ranges over all sets of properties of type (e→σ)→o. Then every rigid condition c built in the object language L gives a deep instance Ax1GenR c that holds at every world. Mathematically this is universal instantiation in a standard model. When every set of properties is in the domain, the set defined by c is one of the Φ that the shallow axiom quantifies over. Nothing below states this lemma for a deep syntax of L-conditions. Several sources come close to it, as listed below.

The local sources contain the ingredients but not the statement. `sources/2609.36279/v4/main.tex` defines the following:
- §"Hybrid witnesses" (sec:criterion), Definition def:hybridfree: at the non-lifted type (e→σ)→o, a substituted set must be "a condition formed in L", i.e. validity of L-formulas combined by connectives and by non-world quantifiers. That is the notion of a rigid L-condition in K3.
- §"Ax1GenR: rigid sets" (sec:rigid): this section introduces Ax1GenR. It uses one specific rigid L-condition, {ψ | A(Pos ψ)}, as the instance Φ. Lean theorem `L_R_rigidpos` (with `PosGlobal`, `Ax1GenR` in `anc/OpenQuestions/lean/OpenQuestions/Ax1GenRigidVariant2.lean`) checks it, and the detector accepts it.
- Definition def:lgeneral: standard models, where every P_τ is full, as opposed to L-general models.
- Proposition prop:lgeneral: soundness over L-general models for proofs whose instances are L-terms.

So the paper instantiates Ax1GenR with particular L-conditions in the shallow embedding, and it has a semantic soundness result. It does not have a deep embedding of L-conditions at higher type, or a general lemma "every deep rigid L-condition is an admissible instance". Its deep embedding (`Separation.thy`/`Separation.lean`, Example ex:separating) covers only the propositional part, and the paper says the higher types "rest on (a)". `sources/2609.26806` (Lean/THF port) only treats Ax1Gen in the shallow embedding.

On the web, the deep/shallow faithfulness line by Benzmüller (and Kirchner) has mechanised results for propositional modal logic, first-order modal logic and monadic second-order logic. The MSO entry includes a `Faithful_to_Standard` theorem: with full ranges, shallow validity matches deep standard validity, comprehension included. That is the same mechanism as K3, but for MSO and not for higher-order modal logic with Ax1GenR. Both 2608.07578 and 2609.36279 call a deep embedding of full higher-order modal logic future work. I found no published statement of K3 itself. The search does not show that the result is new. It is close to immediate from the definitions.
