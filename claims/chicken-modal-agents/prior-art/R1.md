# Prior-art answer for R1 (K7: the Chicken family Q_k with exact thresholds)

Verdict: none found.

- No source defines Q_k = Box^k(False) OR NOT Box(p AND q) or any other family of modal agents for Chicken with exact threshold laws in a nesting index.
- The closest work is "Modal Chicken" (2015): named agents (SwerveBot, NerveBot, CarefulBot, AstuteBot) with informal, partly incorrect claims, and a comment suggesting graded CarefulBots without proof. Mennen (2017) gives a general framework and existence results for non-PD games but no agent families.

## Sources searched (owner, web search, 2026-10-20)
- Mennen, "Modal combat for games other than the prisoner's dilemma" (LessWrong / Alignment Forum, 2017): framework for modal agents in games with any number of players and actions (player types, ranks, opponent tests naming a target player, an agent to test against and an action); existence and Pareto theorems; no agent families with index laws, no enumeration.
- Gram_Stone, "Modal Chicken" (LessWrong, 2015) and its comments (AlexMennen, SilentCal): SwerveBot, NerveBot, CarefulBot, AstuteBot; informal claims about graded CarefulBots and BoldBots.
