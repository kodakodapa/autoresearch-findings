# Prior-art answer for R1 (K11: W_n thresholds against F_k, P_j and each other)

Verdict: none found.

- No source defines the W_n family or states thresholds of this kind (W_n/F_k iff k<n; W_n/P_j iff 2<=n<j; W_n/W_m mutual defection).
- Closest related construction: Barasz et al. 2014 define WaitFairBot_K, which delays with the K-fold box (cooperate iff not Prov^K(false) and Prov(X cooperates)). They use it only to show an obstacle to optimality: an agent that defects against DefectBot fails to cooperate with WaitFairBot_K for large K. The delay technique is therefore known; the W_n gate and its threshold results were not found.
- Suggest citing WaitFairBot_K as the nearest relative.
